# Findings

The study asks one question — **which benchmarks give a reliable signal at
each stage of multilingual training?** — and splits it into research questions
(RQs) grouped by theme. Each page states the question, how we measure
it on the [ladder](../ladder.md), an interactive view of the results and what
to take from it.

## The research questions

| theme | RQ | question |
|---|---|---|
| A · Is the evaluation predictable? | [RQ0](gate.md) | Which benchmarks are above chance, in which language, from which model size? |
| | [RQ1](scaling.md) | Which scores move with model size and training in a way a trend line captures? |
| | [RQ2](decision-accuracy.md) | Does a small model, or an early checkpoint, rank training choices like the 1.7B model? |
| B · Can it be measured cheaply? | [RQ3](noise-snr.md) | How much does a score move by chance, and how large is a real difference against that noise (SNR)? |
| | [RQ4](surrogates.md) | Which statistic, computed on the small model alone, predicts that it ranks correctly? |
| C · Does it generalise? | [RQ5](design-decisions.md) | For each training choice, which proxy sizes read it correctly, and how early? |
| | [RQ6](language-transfer.md) | Does what we learn transfer to languages we did not measure, or never trained on? |
| | [RQ7](external.md) | Do our SNR values agree with AllenAI's DataDecide on English? |
| D · Can benchmarks be improved? | [RQ8](subsets.md) | Can a subset of a benchmark beat the full set? |
| | [RQ9](benchmark-design.md) | Which design features make a benchmark reliable? |
| | [RQ12](above-chance-items.md) | Do the scores get more reliable if we keep only the questions the 1.7B model answers above chance? |
| E · Past the reference | [RQ10](size-generalisation.md) | Does a ranking that holds at 1.7B still hold at 3B? |
| F · The recommendation | [RQ11](recipe.md) | Which benchmark, posed and scored how, gives a reliable decision from the smallest model? |
| Sanity check | [RQ13](english-only.md) | Do the English-only models do better on English benchmarks, as they should? |

Every number on these pages comes from the committed analysis tables under
`src/signal-and-noise/analysis/`, regenerated by
`scripts/refresh_analysis.sh`; the "What we find" blocks are quoted from the
RQ READMEs at build time.
