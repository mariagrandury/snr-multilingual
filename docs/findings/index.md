# Findings

The study asks one question — **which benchmarks give a reliable signal at
each stage of multilingual training?** — and splits it into ten research
questions (RQs) in four themes. Each page states the question, how we measure
it on the [ladder](../ladder.md), an interactive view of the results and what
to take from it.

## Three ideas to read every page

**Signal** is how far apart a benchmark puts the recipes you compare.
**Noise** is how much a score moves when nothing changes but the checkpoint
or the seed. Their ratio, the **SNR**, says whether a difference is real.
**Decision accuracy** is the ground truth: the share of recipe pairs that a
small model (or an early checkpoint) orders the way the large model does.
Play with the simulator: shrink the gap or raise the noise and watch the
decision accuracy fall towards a coin flip (50 %).

## The research questions

| theme | RQ | question |
|---|---|---|
| A · Is the evaluation predictable? | [RQ0](gate.md) | Which benchmarks beat chance at each size? |
| | [RQ1](scaling.md) | Which measurements scale predictably with size and training? |
| | [RQ2](decision-accuracy.md) | Does a small model, or an early checkpoint, rank recipes like the reference? |
| B · Can it be measured cheaply? | [RQ3](noise-snr.md) | How noisy is each benchmark, and what is its SNR? |
| | [RQ4](surrogates.md) | Which cheap statistic predicts decision accuracy? |
| C · Does it generalise? | [RQ5](design-decisions.md) | Which proxy sizes read each design decision correctly, and how early? |
| | [RQ6](language-transfer.md) | Does scaling transfer to languages we did not measure, or never trained on? |
| | [RQ7](external.md) | Do our SNR values agree with AllenAI's DataDecide? |
