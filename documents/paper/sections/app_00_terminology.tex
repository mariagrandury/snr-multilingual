\section{Terminology}

This appendix defines the terms that recur in the paper and its appendices. Table~\ref{tab:notation-symbols} then lists the symbols for the training grid (top) and for the evaluation (bottom).

\begin{description}[leftmargin=0pt,itemsep=2pt,topsep=4pt]
\item[Scaling predictability.] The property that ``evaluation results from small-scale models reliably predict ablation effects in their larger-scale counterparts''\citeneeded{source of the quote}.
\item[Model configuration and model variant.] A configuration $\theta$ records the design choices of a training run (Table~\ref{tab:notation-symbols}). The variants of one design choice are configurations that differ in exactly one of these choices.
\item[Run.] A run is one trained model, given by its configuration and its random seed $S$.
\item[Ladder and rung.] A ladder is a series of runs that share one recipe and differ only in size $N$. Each size is a rung. We train four ladders: deep (the baseline), shallow, deep + SwiGLU and deep + Muon (Appendix~\ref{app:methodology}).
\item[Data build.] A data build is one training-data recipe: the list of training languages, the English corpus and the sampling temperature. We train seven builds, named A, AT3, B, ZH, ES, DCLMP and FWEB (Appendix~\ref{app:data-mixtures}). Each build sets a language-selection scheme $M$ and a temperature $T$.
\item[Language task.] A language task $b_\ell$ is one benchmark $b$ in one language $\ell$, for example HellaSwag-es.
\item[Proxy and reference point.] A proxy point $(N, f)$ is a cheaper place to rank the variants: a smaller size, an earlier checkpoint, or both. The reference point is the final checkpoint at the reference size, 1.7B unless stated otherwise.
\item[Chinchilla multiple.] One Chinchilla multiple (1C) is a budget of $20N$ tokens. Every run trains on $100N$ tokens, which is 5C, so 20\% of a run is 1C.
\item[Above-chance gate.] A language task enters the analysis at a size only if at least half of the seed-1904 runs of that size score above chance on it (Appendix~\ref{app:chance-threshold}).
\item[Ranking agreement and decision accuracy.] Ranking agreement (RA) asks whether a proxy point ranks the variants as the reference point does. Decision accuracy (DA) is the share of variant pairs on which the two agree (Appendix~\ref{app:ranking-agreement}). DA-size compares a smaller final model with the reference size, and DA-ckpt compares an earlier checkpoint with the final checkpoint of the same size.
\item[BPB and bBPB.] Bits-per-byte (BPB) is the negative log-likelihood of held-out text in bits, divided by the text's UTF-8 byte count. Benchmark BPB (bBPB) applies the same measure to the gold answer of each benchmark item (Appendix~\ref{app:evaluation-protocol}).
\item[Seed noise.] Seed noise is the spread between runs that differ only in their random seed. The replicate seeds of Appendix~\ref{app:training-grid} measure it.
\end{description}
