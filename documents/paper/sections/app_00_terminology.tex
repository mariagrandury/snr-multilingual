\section{Terminology}

A PRIORI EVERYTHING SHOULD BE CLEARLY DEFINED IN THE CORRESPONDING SECTIONS, THIS IS TO ALIGN INTERNALLY ABOUT CONCEPTS

\textbf{Scaling predictability.} The property that ``evaluation results from small-scale models reliably predict ablation effects in their larger-scale counterparts''.

\textbf{Model configuration and model variant.} A configuration $\theta$ records the design choices of a training run (Table~\ref{tab:notation-models}). The variants of one design choice are configurations that differ in exactly one of these choices.

\textbf{Run.} A run is one trained model, given by its configuration and its random seed $S$.

\textbf{Ladder and rung.} A ladder is a series of runs that share one recipe and differ only in size $N$. Each size is a rung. We train four ladders: deep + ademamix (the baseline), shallow + ademamix, deep + SwiGLU, and deep + Muon (Appendix~\ref{app:model-ladder}).

\textbf{Data build.} A data build is one training-data recipe: the list of training languages, the English corpus and the evaluation.sampling temperature. We train seven builds, named A, AT3, B, ZH, ES, DCLMP and FWEB (Appendix~\ref{app:data-mixtures}). Each build sets a language-selection scheme $M$ and a temperature $T$.

\textbf{Proxy and reference point.} A proxy point $(N, f)$ is a cheaper place to rank the variants: a smaller size, an earlier checkpoint, or both. The reference point is the final checkpoint at the reference size, 1.7B unless stated otherwise.

\textbf{Chinchilla multiple.} One Chinchilla multiple (1C) is a budget of $20N$ tokens. Every run trains on $100N$ tokens, which is 5C, so 20\% of a run is 1C.

\textbf{Above-chance threshold.} A language task enters the analysis at a size only if at least half of the seed-1904 runs of that size score above chance on it (Appendix~\ref{app:chance-threshold}).

\textbf{Ranking agreement and decision accuracy.} Ranking agreement (RA) asks whether a proxy point ranks the variants as the reference point does. Decision accuracy (DA) is one measure of RA, it is the share of variant pairs on which the two agree (Appendix~\ref{app:ranking-agreement}). DA-size compares a smaller final model with the reference size, and DA-ckpt compares an earlier checkpoint with the final checkpoint of the same size.
